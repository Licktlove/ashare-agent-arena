# A 股 Agent 沙盘

本项目是自主交易沙盘的开发版本。使用 Node.js 22.5 或更高版本，在项目目录运行：

```powershell
node server.js
```

打开 http://127.0.0.1:8765 。数据库存放于本地 `data/arena.sqlite`，不会上传到仓库。

## 已实现

- 独立模拟账户、现金冻结、手动测试限价委托、部分成交、撤单和逐笔事件。
- 限制同一账户重复消费相同买一或卖一深度。
- 国产供应商兼容的 Chat Completions 接口配置，支持每个 Agent 设置模型、接口地址、费率、预算、密钥环境变量和唤醒间隔。
- 模型调用前进行账户及全局预算预留，按返回 token 数与配置费率估算成本。调用异常或用量缺失时保留预留，并允许人工对账。缓存价格、计费工具和不同供应商的其他收费项目尚未单独核算。
- 支持从可配置的外部行情适配服务读取报价，并限制手动测试报价进入模型决策。外部服务需保证其数据来源、时效、数据使用授权与字段准确性。
- 模型决策摘要及费用记录可在页面查看。启用定时决策后，模型可提交模拟委托。当前交易规则与行情源尚未完成验收，结果仅供开发测试。

## 模型配置

在当前 PowerShell 会话设置供应商密钥和总预算，再启动程序。例如：

```powershell
$env:MODEL_API_KEY = '由供应商提供的密钥'
$env:GLOBAL_MODEL_BUDGET_MICRO = '10000000'
node server.js
```

总预算单位是人民币百万分之一元，示例中的 10000000 相当于 10 元。密钥仅存在进程环境，界面只保存变量名。请填写供应商当前的模型 ID、接口根地址和按人民币计的费率。面板中填写的账户预算单位是元。

模型请求可能产生真实费用。接口返回的 token 用量及输入费率估算花费，费用尚需与供应商账单核对。请在供应商侧同步设置限额。超时或中断后的实际费用未知，系统会保留相应预留，使用调用 ID 在界面对账后才释放。进程重启时进行中的调用也进入待对账状态。

## 外部行情适配服务

配置环境变量 `MARKET_FEED_URL`，程序每 5 秒读取一次 JSON 数组。远程地址要求 HTTPS。服务应返回如下标准化字段，价格单位为分，数量单位为股，时间为含时区的 ISO 8601 字符串：

```json
[{"symbol":"SH600000","bid":1000,"ask":1001,"bidQuantity":500,"askQuantity":600,"observedAt":"2026-11-24T02:00:00Z"}]
```

上述数据仅为字段示例，不是行情。报价超过 10 秒、时间超前或字段无效时会被拒绝。行情源本身需要独立部署并完成沪深京覆盖、连续性、停牌状态和授权等验证。目前只使用买一和卖一，未实现五档深度。
